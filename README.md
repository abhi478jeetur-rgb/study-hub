# Study Hub 📚

A growing collection of small, single-file study tools — all in one place.

**Live site:** https://study-hub-abhi478jeetur-rgbs-projects.vercel.app

## Tools

| Tool | What it does |
| --- | --- |
| [Flash Reader](flash-reader.html) | Paste any text and read it one word at a time (RSVP speed reading). |
| [Physics Flash Reader](physics-reader.html) | Physics questions flashed one at a time — pick the answer or reveal it. |
| [Physics Dash — RSVP Speed Reader](physics_dash_rsvp_speed_reader.html) | All 175 physics questions in RSVP study mode. |
| [Physics Dash](physics-dash.html) | A timed race through the physics questions — set seconds per question and go. |

## Adding a new tool

1. Drop the tool's single HTML file into this repo (root folder).
2. Add one card for it in `index.html` (copy any existing card and change the link, title and line of description).
3. Push — Vercel redeploys automatically.

Every tool keeps its own original UI; the home page only links to them.
